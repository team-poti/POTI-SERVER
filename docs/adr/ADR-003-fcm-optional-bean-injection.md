# ADR-003: FCM 선택적 빈 주입 (@Autowired required=false + @Profile)

**상태:** 채택됨  
**결정일:** 2026.07

---

## 컨텍스트

알림 기능은 Phase 2 MUST 기능이지만, CI 테스트 환경에는 Firebase가 없다. Firebase 빈 초기화 실패가 테스트 빌드를 깨뜨리면 안 된다.

또한 알림 발송은 분철 거래 플로우의 **부가 기능**이다. 알림 발송에 실패해도 입금 확인·배송 등록 등 핵심 거래는 반드시 정상 처리되어야 한다.

---

## 결정

두 가지 방어 장치를 조합한다.

1. `@Profile("!test")`: FcmNotificationService 빈 자체를 테스트 환경에서 생성하지 않는다.
2. `@Autowired(required = false)`: FCM 서비스를 호출하는 서비스에서 빈이 없어도 실패하지 않도록 선택적으로 주입한다.

사용 시점에는 null 체크 후 호출한다.

---

## 이유

- `@Profile("!test")`만 적용하면 테스트에서 빈이 없을 때 의존성 주입 실패로 NPE 발생.
- `required = false`로 Optional 주입하면 빈 없이도 컨텍스트가 정상 로드된다.
- FCM 발송 실패가 거래 트랜잭션을 롤백시켜서는 안 된다는 원칙을 구조적으로 보장한다.

---

## 결과

- CI 테스트에서 Firebase 없이 빌드·테스트 정상 통과.
- FCM 발송 실패는 경고 로그만 남기고, 트랜잭션에 영향을 주지 않는다.
- 적용 서비스: 주문 생성, 입금 제출, 입금 확인, 배송 등록, 배송 완료 확인 총 5개 흐름.
